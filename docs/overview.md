# プロジェクト概要

**バージョン：** 1.3.0  
**作成日：** 2026-05-12  
**対象：** AAAタイトル開発会社（CAPCOM想定）転職用ポートフォリオ

---

## 1. 目的

インフラエンジニアとしての技術力を示すポートフォリオ作品として、AWSを活用したリアルタイムマルチプレイヤーゲームのバックエンドインフラを構築する。

## 2. コンセプト

> **「ゲームの完成度ではなく、スケーラブルなインフラ設計で勝負する」**

ゲームロジックはシンプルに保ちつつ、以下の技術力を前面にアピールする。

- グローバル対応のマルチリージョン設計
- IaC（Infrastructure as Code）による完全再現可能な環境
- 負荷テストによる数値で語れる実績
- SRE的な監視・障害対応設計

## 3. 想定ターゲット企業

| 項目 | 内容 |
|------|------|
| 想定企業 | CAPCOM（株式会社カプコン） |
| 参考タイトル | モンスターハンターシリーズ、ストリートファイター6 |
| 想定ポジション | インフラエンジニア／クラウドエンジニア |

## 4. 技術スタック

| レイヤー | 技術 |
|---------|------|
| ゲームエンジン | Unity（Personal / バージョン2022 LTS以上） |
| クライアント言語 | C#（.NET） |
| サーバー言語 | Go |
| クラウド | AWS |
| IaC | Terraform |
| 通信 | UDP（GameLift SDK）/ HTTPS |
| CI/CD | GitHub Actions + AWS CodePipeline |
| 監視 | CloudWatch + X-Ray |
| 負荷テスト | k6 |

## 5. 面接でアピールする数字

| 指標 | 目標値 |
|------|--------|
| 同時接続セッション数 | 1,000セッション（4,000接続） |
| 東京リージョン レイテンシー | 50ms以内 |
| スケールアウト時間 | 3分以内 |
| IaCカバー率 | 100%（全インフラTerraform管理） |
| 環境再構築時間 | 15分以内 |
| コスト最適化 | Spot Instance活用で約40%削減 |

---

## 6. コスト試算

### AWS月額コスト

| 期間 | 主なサービス | 月額概算 |
|------|------------|---------|
| Phase 0〜2（〜1ヶ月） | EC2・Cognito・DynamoDB（ローカル中心のためAWS最小） | 約$30 |
| Phase 3〜4（〜1.5ヶ月） | EC2・GameLift×2・DynamoDB・CloudWatch | 約$170 |
| Phase 5〜6（〜1.5ヶ月） | 上記 + マルチリージョン追加 | 約$320 |

### 総コスト

| 項目 | コスト |
|------|--------|
| AWS費用（4ヶ月） | 約$750（約11万円） |
| Unityライセンス | 無料（Personal） |
| その他ツール | 無料（Terraform・Docker・GitHub・k6） |
| **総計（金銭）** | **約11万円** |
| **総計（時間）** | **約260時間** |

> ローカル環境を先行整備することで、Phase 0〜2のAWSコストを大幅に削減。

### コスト削減施策

- **ローカルファースト開発**でAWSへのアクセスを必要最小限に抑える
- GameLiftはSpot Instanceを優先使用（最大70%削減）
- 未使用時はGameLiftフリートを停止（スクリプトで自動停止）
- AWS Budgetsで上限アラート設定（$200/月）
